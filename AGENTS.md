# Планировщик — правила проекта

Проект: трекер «план vs факт» (Supabase + Telegram Mini App + CLI для OpenCode).
Смежные файлы планировщика лежат выше: `../plan.md`, `../progress.md`, `../AGENTS.md`.

## Каждая сессия

1. Загрузить скилл `dev-rules`.
2. Прочитать только `docs/HANDOFF.md` и `docs/TASKS.md`.
3. Дальше — точечные чтения. Не сканировать проект целиком, не открывать `node_modules`, `dist`, `.git`.

## Каждая задача

- Одна небольшая подзадача за раз, минимальный diff.
- В конце: обновить `docs/TASKS.md`, перезаписать `docs/HANDOFF.md`.
- Секреты только в `.env` (в `.gitignore`). Никогда не печатать ключи в чат.

## Домен

- План и факт — одна строка `daily_tasks`; время задачи = сумма `task_sessions`.
- Пауза не принадлежит задаче; «пауза-дело» живёт в `fact_logs`.
- Хвосты и переносы — только на десктопе, в мобильном их нет.
- Планирование и разбор — через скилл `daily-tracker`, не придумывать данные руками.
